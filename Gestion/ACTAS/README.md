# 📂 Actas y Evolución de Planeación

Este directorio contiene los documentos de gestión, seguimiento y planeación del proyecto del grupo **TrackLogic**. Su propósito es dejar evidencia clara de las reuniones, decisiones técnicas, avances y tareas realizadas durante el desarrollo del sistema biomédico para monitoreo de atletas.

Las actas permiten mantener trazabilidad completa del proyecto, mostrando cómo el equipo evolucionó desde la organización inicial y revisión de componentes hasta la integración funcional del hardware, desarrollo del firmware, validación de sensores y consolidación final del sistema.

# 🔄 Evolución de la planeación actual

La planeación del proyecto TrackLogic evolucionó progresivamente desde la organización inicial del equipo hasta la validación completa del sistema biomédico funcional.

Inicialmente, el equipo se enfocó en:

* Organización de tareas.
* Creación del repositorio GitHub.
* Planeación general del proyecto.
* Investigación técnica de sensores y módulos electrónicos.

Posteriormente, se realizó:

* Verificación del hardware disponible.
* Recepción y validación de componentes.
* Integración electrónica del sistema.
* Desarrollo del firmware principal.

Más adelante, el proyecto avanzó hacia:

* Lectura estable de variables fisiológicas.
* Implementación de alertas automáticas.
* Comunicación WIFI y Telegram BOT.
* Validación funcional de sensores biomédicos.

Finalmente, el equipo consolidó:

* Protocolos de prueba y validación.
* Requisitos funcionales y no funcionales.
* Definition of Done (DoD).
* Organización completa del repositorio GitHub.
* Informe técnico y documentación final del sistema funcional.
