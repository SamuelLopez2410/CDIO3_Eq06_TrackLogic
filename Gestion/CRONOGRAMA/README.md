# 🚀 TrackLogic

**Estado:** En Desarrollo
**Hardware:** ESP32
**Fase:** Semanas 7 - 8

**Autores:** Equipo TrackLogic
**Programa:** Ingeniería Electrónica

TrackLogic es un sistema embebido enfocado en la adquisición y análisis de señales biométricas y de movimiento. Este repositorio contiene el firmware, el diseño de hardware y la documentación técnica correspondiente al desarrollo del prototipo funcional del sistema.

# 🛠️ Tecnologías Utilizadas

* **Microcontrolador:** ESP32
* **Sensores:** MPU6050, MAX30102, MAX30105, MLX90614
* **Lenguaje:** C/C++ (Arduino / ESP-IDF)
* **Software:** VS Code, Proteus
* **Hardware:** PCB en baquela y diseño mecánico (chaleco)
